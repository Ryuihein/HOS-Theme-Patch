# HOS-Theme-Patch
To apply custom themes in HOS: ( As a non - rooted user)
1. Use these shell scripts to apply the theme
2. you can also automate the pkg installation ( Tested + Works in HOS 1 )
3. Set up the apk called as "mtz installer pro". you'll find on web. 


This procedure can permanently apply a custom theme on HOS 1. 

Make sure Shizuku service is enabled.
